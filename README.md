# OlympiadGate

OlympiadGate — программа для Windows. При входе в выбранную обычную учётную запись она закрывает рабочий стол, пока ученик не решит заданное на сегодня число задач. Настраивает её администратор компьютера. Учётные записи из группы «Администраторы» программа не блокирует.

Поиск задач в интернете в эту версию не входит. Администратор вносит задачи вручную или загружает пачкой из JSON.

## Ученик

При входе ученик видит название текущего направления и одну случайную задачу своего класса, которую он ещё ни разу не решил верно. На экране поле ответа и кнопка «Проверить». Закрыть этот экран нельзя: он закрывает все мониторы, а служебные сочетания клавиш рабочего стола не проходят. Если окно закроют, служба открывает его снова.

Ответ сверяется без лишних пробелов и без учёта регистра. Запятая в десятичной дроби равна точке. Верным считается любой из допустимых вариантов. Неверный ответ не тратит задачу и не двигает счётчик: можно отвечать на ту же задачу снова. После верного ответа приходит следующая случайная нерешённая задача.

Когда за сегодня набрано нужное число верных ответов, экран закрывается до местной полуночи. Повторный вход в тот же день открывает обычный рабочий стол. На следующий день счётчик снова с нуля, уже решённые задачи не повторяются.

Если подходящие задачи кончились, экран остаётся закрытым и просит позвать администратора.

Ctrl+Alt+Del программа не перехватывает. Этим сочетанием администратор может сменить пользователя. Обход через безопасный режим или другую учётную запись администратора тоже остаётся возможным.

## Администратор

Панель открывается только с правами администратора. В ней три раздела: «Учётки», «Банк задач» и «Справка».

Для каждой локальной учётки администратор включает или выключает замок, указывает класс, текущее направление, при желании олимпиаду, число верных ответов за календарный день и порог предупреждения. Можно снять блокировку совсем или открыть доступ до конца текущего дня.

Предупреждение жёлтое, когда нерешённых задач текущего направления меньше двух дневных норм. Красное — когда их не хватает даже на сегодня. Порог можно изменить.

Справка открывается из левого меню и клавишей F1. Пока замок никому не включён и банк пуст, сверху видна плашка со ссылкой на справку. На экране ученика этой инструкции нет: там номер задачи, условие, кнопка подсказки и поле ответа. В справке написано, как настроить программу, переключить направление, добавить задачи, что делать, если ученик застрял, и как удалить программу.

## Направления

Направление — это предмет: математика, природоведение, русский язык или любое другое имя. Задачи разных направлений лежат в одном банке. У учётки включено одно направление, и замок берёт задачи только из него.

Направление выбирается на карточке учётки из уже использованных имён или вписывается новое. «Математика» и «математика» — одно и то же направление, на экране остаётся первое написание. Класс и дневная норма при смене направления не меняются.

Олимпиада необязательна. Пустая олимпиада означает все задачи этого направления и класса. Заполненная сужает выбор до этой олимпиады. Если в новом направлении нет задач указанной олимпиады, панель сообщает об этом до сохранения и предлагает очистить поле.

Смена направления не стирает уже решённые задачи. Если сегодняшняя норма уже закрыта, рабочий стол остаётся открытым до полуночи, а новое направление начнётся со следующего входа после полуночи. Если норма ещё не закрыта, оставшиеся задачи этого дня берутся из нового направления. Возврат к математике продолжает нерешённые задачи по математике.

## Банк задач

Задачу можно добавить тремя способами. Все они пишут в один банк.

Одна задача вводится формой: условие, подсказка для ученика, ответы по одному на строку, комментарий к решению, направление, класс, необязательная олимпиада и короткая пометка. Номер задача получает при сохранении. Он виден в списке банка и на экране ученика, по нему задачу можно найти в поиске. Подсказку ученик открывает сам: она подводит к способу и не содержит ответ. Комментарий к решению и пометку видит только администратор. В комментарии описывают, как прийти к ответу. Ctrl+Enter сохраняет задачу и очищает условие, ответы, подсказку и комментарий. Направление, класс и олимпиада остаются. Двойной щелчок по строке списка открывает задачу в той же форме.

Пачка загружается из файла JSON или вставкой текста из чата. Перед записью показывается предпросмотр: что добавится, что уже есть, какие строки с ошибкой. Ошибочные строки в банк не попадают. Остальные сохраняются вместе. Дубль — то же условие в том же направлении, классе и олимпиаде. По умолчанию дубль пропускается. Отдельный флажок обновляет ответы, подсказку и комментарий к решению у уже существующей задачи. Одинаковый текст в разных направлениях дублем не считается.

Кнопка «Сохранить инструкцию для нейросети» кладёт рядом текст задания и пример JSON. В текст уже подставлены направление, класс и олимпиада. Этот текст вместе с задачником можно отдать модели и попросить вернуть только JSON.

Канонический файл:

```json
{
  "direction": "Природоведение",
  "grade": 4,
  "olympiad": "Школьный этап",
  "problems": [
    {
      "statement": "Какой газ выделяют растения на свету?",
      "answers": ["кислород"],
      "hint": "Вспомни, что растения делают с углекислым газом днём.",
      "solution": "На свету идёт фотосинтез: растения поглощают углекислый газ и выделяют кислород."
    },
    {
      "statement": "Сколько ног у паука?",
      "answers": ["8", "восемь"],
      "note": "достаточно числа"
    }
  ]
}
```

`direction`, `grade` и `olympiad` можно задать на весь файл и перекрыть в отдельной задаче. `olympiad`, `hint`, `solution` и `note` можно не указывать. `statement` — полное условие без решения. `answers` — короткие ответы, которые вводит ученик. `hint` — подсказка ученику: способ, но не ответ. `solution` — комментарий к решению для администратора. Один ответ тоже записывается массивом из одной строки. Класс — целое число от 1 до 11. Направление и условие обязательны, нужен хотя бы один непустой ответ. Подсказка, которая целиком совпадает с ответом, в банк не попадает. Номер задаче назначает программа.

## Установка и удаление

Номер версии записан в `version.txt`. Та же версия стоит в панели администратора и в имени установщика. Готовый файл для 64-разрядной Windows публикуется при теге `v` с этим номером, например `v1.0.0`: https://github.com/Skirgus/OlympiadGate/releases/latest

Администратор скачивает `OlympiadGate-<версия>-Setup.exe` и подтверждает запрос Windows. Мастер на русском языке копирует программу в `C:\Program Files\OlympiadGate`, создаёт данные в `C:\ProgramData\OlympiadGate`, ставит службу в автозапуск и добавляет ярлык «OlympiadGate» в меню «Пуск». В конце можно сразу открыть панель. Повторный запуск мастера обновляет программу и не стирает банк задач.

Удаление запускается кнопкой «Удалить программу» в справке или через «Параметры Windows → Приложения → OlympiadGate». Оба пути снова спрашивают права администратора. Служба, ярлык и временные запреты диспетчера задач снимаются вместе с программой. Банк задач по умолчанию остаётся. Отдельная галочка удаляет и его.

## Состав программы

Программа на C# и .NET 8: интерфейс WPF, служба Windows и база SQLite. Служба одна записывает базу. Панель администратора и экран ученика передают ей команды. Публикация self-contained для 64-разрядной Windows, отдельно ставить среду .NET не нужно.

Позже можно добавить загрузку задач из интернета по направлению, классу и олимпиаде, формулы и картинки к условию. Банк, замок и учёт прогресса при этом остаются теми же.
